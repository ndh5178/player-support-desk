# 구현 계획

이 문서는 현재 작업 순서와 완료 상태를 관리합니다. 세부 요구사항은 `PROJECT_SPEC.md`, 작업 단위와 완료 기준은 `WORK_UNITS.md`, Git 절차는 `GIT_WORKFLOW.md`를 기준으로 합니다.

## 진행 원칙

- 핵심 사용자 흐름이 동작하는 상태를 먼저 만들고 세부 품질을 보강합니다.
- 각 단계는 독립적으로 설명하고 검증할 수 있는 브랜치와 커밋으로 진행합니다.
- 완료 표시는 코드 작성뿐 아니라 해당 단계의 검증까지 끝난 경우에만 합니다.
- 구현 과정에서 발견한 기술 결정은 `DECISIONS.md`에 기록합니다.
