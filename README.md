# Player Support Desk

Vue 3와 TypeScript로 구현하는 반응형 게임 고객 문의 관리 대시보드입니다.

현재 Vue·TypeScript·Vite 개발 환경과 기본 앱 셸, 라우팅, 테스트, MSW 실행 기반을 구성했습니다. 기능 구현과 검증이 완료되면 프로젝트 소개, 화면 자료, 기술 선택, 테스트 결과, Vue 학습 경험을 포함한 공개용 README로 갱신합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run format:check
npm run lint
npm run type-check
npm run test:unit
npm run build
```
