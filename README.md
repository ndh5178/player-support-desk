# Player Support Desk

Vue 3와 TypeScript로 구현하는 반응형 게임 고객 문의 관리 대시보드입니다.

현재는 구현 전 프로젝트 기준과 개발 절차를 정리한 단계입니다. 기능 구현과 검증이 완료되면 프로젝트 소개, 실행 방법, 화면 자료, 기술 선택, 테스트 결과, Vue 학습 경험을 포함한 공개용 README로 갱신합니다.
